# Ys Automóveis

Site institucional / vitrine de uma loja de carros. **Não possui sistema de vendas** —
o objetivo é apenas exibir os veículos disponíveis no showroom.

## Funcionalidades

- Página única (one page) com navegação por seções: Início, Estoque, Sobre e Contato
- Vitrine de carros em formato de cards, com foto, ano, quilometragem e preço
- Filtro por categoria (Hatch, Sedã, SUV, Picape, Esportivo)
- Modal com os detalhes completos de cada carro
- Layout responsivo (desktop e celular)

## Como usar

Basta abrir o arquivo `index.html` em qualquer navegador.

## Estrutura

- `index.html` — estrutura da página
- `styles.css` — estilos
- `cars.js` — lista de carros (edite aqui para adicionar/remover veículos)
- `script.js` — lógica de exibição (filtros e modal)

## Adicionando um carro

Edite o arquivo `cars.js` e acrescente um novo objeto na lista `cars` seguindo o
modelo dos existentes (nome, categoria, ano, km, câmbio, combustível, cor, motor,
preço, badge, descrição e imagem).
